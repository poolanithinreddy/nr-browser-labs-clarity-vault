# Screenshots

This directory contains store-quality screenshots for Chrome Web Store and Firefox Add-ons submissions.

## Required screenshots (1280×800 or 640×400)

| Filename | Content |
|---|---|
| `01-recent-tab.png` | Popup open on Recent tab showing captured clips with domain labels, timestamps, and action buttons |
| `02-vault-search.png` | Vault tab with search active, domain + tag filters, starred filter, showing filtered results |
| `03-summary.png` | Summary tab showing a clip from an AI site — local TextRank summary on top, original below |
| `04-analyze-page.png` | A real web article with Opinion, Promotional, and Neutral chips injected inline |
| `05-settings-options.png` | Full options/settings page showing privacy statement, permissions table, and capture settings |

## How to capture

1. Load the extension as unpacked in Chrome (Developer Mode → Load unpacked → select `extension/`).
2. Visit a real article and copy several paragraphs to build up the vault.
3. Use a screen capture tool at 1280×800 (Chrome DevTools device emulation can help with consistent sizing).
4. Crop to show only the popup or the relevant area.
5. Save as PNG.

## Tips

- Use the dark theme for the primary screenshot set.
- Show real content (not placeholder text) — reviewers reject fake data.
- The Analyze screenshot should show a real page with diverse label types.
- Avoid showing any sensitive personal data in clips.
