Settings & Privacy

Privacy

🔒
100% local storage

Every clip is stored in chrome.storage.local on this device only. Nothing leaves your browser.

🚫
No servers · No accounts · No cloud sync

There are no servers, no sign-in, and no telemetry of any kind.

🧠
On-device AI analysis

Summaries (TextRank) and page labels (rule-based classifier) run entirely in your browser. No external AI API is used.

🗑️
You control your data

Export everything as JSON or Markdown, or delete everything, at any time below.

Why these permissions?

PermissionWhy it is needed
storage Saves clips, settings, and UI preferences locally in chrome.storage.local.
activeTab Analyzes the page you are currently viewing when you click "Analyze this page".
scripting Injects the page analyzer and copy listener scripts when you enable them.
contextMenus Adds a "Save selection to Clarity Vault" option to the right-click menu.
host_permissions (<all_urls>) Declared so the auto-capture content script can be registered at runtime. It is only used when you explicitly enable Auto-capture or run Analyze. It is never used silently in the background.
